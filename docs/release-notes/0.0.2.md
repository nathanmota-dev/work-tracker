Work Tracker 0.0.2 brings a redesigned interface, smarter resume handling and new tools for every stage of the job search.

## New look

- Jobs, Applications, Profile, Resumes, Interviews, Interview prep, Contacts and Dashboard now use a card-based layout with tabs, search and filters (#90, #91, #93).
- Discover opportunities moved into its own Jobs view, opened from the page header (#90).
- Interviews can be added, edited, marked done, closed and deleted from the app, with a "Next conversation" highlight and countdown (#93).

## Jobs and ranking

- Batch job ranking with technical, experience and career-alignment scores (#78), and a smoother flow to rank the best opportunities (#92).
- Deterministic ATS resume match score for each job, with no AI involved (#85).
- New LinkedIn jobs saved without a description get one fetched in the background, so their match score appears automatically (#92).
- Requirement gates flag jobs that need languages or work authorization you don't have (#79).
- Posting integrity guard removes hidden text and flags tampered job postings (#73).
- Optional deadlines for jobs and applications, with overdue and due-soon badges (#70).

## Resumes and applying

- Reusable resume variants (#84); approved tailored resumes are saved in Resumes so similar jobs can reuse them (#89).
- Generated PDFs are checked for layout problems and a valid text layer (#72).
- Profile is consolidated from your LinkedIn "Save to PDF" export and reference resumes, and empty answers are filled automatically (#83, #88).
- Typed profile answer fields, tag inputs and a shared date picker; portal forms in Portuguese are filled from your answers.
- Editing a job's link updates its unsubmitted applications (#86).
- Applications can be advanced to tracking from the board.

## Follow-up and interviews

- Interview preparation page that builds a prep pack for an application (#63).
- Follow-up and thank-you message drafts — nothing is ever sent automatically (#75).
- Quiet application sweep lists submitted applications with no activity for a while (#71).
- Company research is cached for 30 days (#74).

## Setup and reliability

- Profile file uploads, and the default LinkedIn and Chrome MCP servers are installed automatically when missing (#87).
- The Chrome sign-in is preserved when the app quits.
- Refined agent console layout.
